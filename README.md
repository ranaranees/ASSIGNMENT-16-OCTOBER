# 📊 E-Commerce Sales Analysis | Power BI

## Overview
An interactive Power BI dashboard analyzing e-commerce sales, profitability, monthly trends, and sales targets using DAX and data visualization.

## Tools Used
- Microsoft Power BI
- DAX
- Power Query

## Key Features
- Actual Sales vs. Targets
- Monthly Sales Trends
- Profit by Sub-Category
- Profit vs. Quantity Analysis
- Total Sales and Target KPIs
- Sales Performance Matrix
- Sales by Sub-Category Treemap
- Order Count by State Funnel

## Skills Demonstrated
Data Cleaning | Data Modeling | DAX | Data Visualization | Business Intelligence

## Dataset
- List of Orders
- Order Details
- Sales Targets
